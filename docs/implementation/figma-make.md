IMPORTANT:

Before generating any screen:

1. Read documents in this exact order:
   Constitution
   Roadmap
   Domain Blueprint
   User Journeys
   UX Rules
   UX Master Blueprint
   Visual Language
   Design System Mapping
   Frontend Architecture

2. Product is the center of the platform.

3. Never design a generic CMS.

4. Never design a generic admin panel.

5. Never design isolated screens.

6. Every screen must preserve:

Platform
→ Tenant
→ Product
→ Module
→ Resource

7. User must always answer:

Where am I?
What am I managing?
What happened recently?
What should I do next?

8. Generate incrementally.
Do not generate the entire platform at once.
