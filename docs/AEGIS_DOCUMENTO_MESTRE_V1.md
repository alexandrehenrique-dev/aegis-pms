# ⚠️ Documento Descontinuado

Este arquivo (`AEGIS_DOCUMENTO_MESTRE_V1.md`) foi **descontinuado** e não deve mais ser lido, editado ou referenciado como fonte de verdade.

## Por quê

O projeto tinha três documentos competindo pelo papel de "documento mestre":

1. **`AEGIS_PMS_V1.md`** — versão completa e detalhada (DDL de banco, contratos JSON, diagramas, "Leis" por domínio).
2. **`AEGIS_DOCUMENTO_TECNICA.md`** — versão condensada da mesma estrutura (Parte I–VIII, seções 1–48).
3. **Este arquivo** — uma terceira versão, redundante, com boilerplate excessivo e sem a profundidade de CMS_V1 nem a objetividade de TECNICA.

`docs/README.md` apontava para este arquivo como fonte de verdade, mas os outros dois documentos eram mais completos e mais usados na prática. Para eliminar a ambiguidade, este arquivo foi aposentado.

## Onde ler agora

- **Fonte de verdade:** [`AEGIS_PMS_V1.md`](./AEGIS_PMS_V1.md)
- **Versão condensada / leitura rápida:** [`AEGIS_DOCUMENTO_TECNICA.md`](./AEGIS_DOCUMENTO_TECNICA.md)
- **Índice geral:** [`README.md`](./README.md)
